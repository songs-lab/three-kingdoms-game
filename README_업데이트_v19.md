# 삼국지 백팩 배틀즈 v19 — 21~45라운드 적군 초상화 보완

기반: v18 전체 게임 코드. **적군 편성·전투력·기술·특성·상점·금화·지도·회복 규칙은 변경하지 않음.**

## 변경 사항
- 21~45R의 417개 적군 배치 중 이름에 대응하는 기존 초상화 좌표가 없던 208건 확인.
- `감녕(강하)` 2건과 `제갈량(신야)` 1건은 기존 인물의 초상화를 재사용하므로 별도 제작 불필요.
- 누락된 서로 다른 109명의 신규 창작 초상화를 세 장의 WebP 스프라이트 시트(`faces/enemy_extra_01.webp` ~ `03.webp`)에 배치하고 `portraitAtlas`에 이름별 실제 좌표 연결.
- 기존 `portraitAtlas` 항목, `faces/enemy.webp`, `faces/shu.webp`, `faces/wei.webp`, `faces/wu.webp`, `faces/other.webp`는 덮어쓰거나 수정하지 않음.
- 추가 시트의 실제 칸 수는 6×5, 8×6, 9×4. 서비스워커 캐시 키를 `tk-battle-v19-enemy-portraits`로 갱신.
- 게임에서 캐릭터 이름과 실제 얼굴 좌표가 맞는지 확인하기 위한 `초상화_검수.html`와 `초상화_매핑_21_45.md` 제공.

## GitHub Pages에 적용
1. 기존 게임 저장소의 `faces/` 등 기존 이미지는 삭제하거나 교체하지 않는다.
2. 압축파일에 포함된 `index.html`, 모든 `.js`, `faces/enemy_extra_01.webp` ~ `03.webp`를 **폴더 구조를 유지해** GitHub Pages 저장소에 추가/교체한다.
3. 기존 `faces/enemy.webp` 및 국가별 이미지와 기타 JSON/manifest 등은 그대로 둔다.
4. 배포 후 브라우저 캐시가 새로고침되도록 온라인에서 재접속한다. 파일 확인은 `초상화_검수.html`로 가능하다.

## 주의
- 세 개의 신규 WebP는 입력 예시의 화풍을 바탕으로 만든 **창작 이미지**로, 사료 속 인물의 실제 얼굴을 고증한 초상화는 아님.
- 109명의 이름에 각각 다른 칸의 이미지를 매핑했으나, 생성된 얼굴과 역사적 인물의 외모·복식의 일치를 보증하지 않음.
- 사용자 제공 `enemy.webp`는 참고용으로만 사용했으며, v19 ZIP에 포함해 덮어쓰지 않음.
- 이 ZIP은 게임 리소스 전체가 아니므로 기존 게임 폴더와 결합해야 정상 플레이 가능.

이미지 검수: `초상화_검수.html`에서 검색하거나, `초상화_전체미리보기.jpg`를 열어 109명 전체 얼굴을 확인할 수 있습니다.
