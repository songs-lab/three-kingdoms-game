# 삼국지 백팩 배틀즈 — v16 적군 전술 개편

2026-11-18 기준 v15 복원본에 새로운 적군 전장 연계 엔진을 추가한 독립 작업본입니다. 기존 1~45라운드 편성·등급·HP·능력치와 플레이어 105명의 데이터를 유지하는 것을 우선했습니다.

## 적용

기존 게임 저장소를 먼저 백업하십시오. 이 ZIP에 포함된 게임 실행 파일을 기존 게임의 루트 폴더에 덮어쓰고, 이전부터 사용하던 다음 리소스는 유지해야 합니다.

- `faces/` 내부의 아군·적군 초상화 및 목록
- `icons/`, `manifest.webmanifest`
- `MAIN.png`, `MAP_BG.png`, `FIGHT.png` 등의 기존 이미지
- 기존에 보유한 `enemy_rounds_01_20.json` 등 다른 프로젝트 자원

새 파일 `enemy-v16-synergy.js`가 반드시 같은 폴더에 있어야 합니다. `index.html`의 `<script>`에서 이 파일을 `enemy-v15-engine.js` 다음에 읽도록 연결했습니다. `service-worker.js` 캐시 이름도 갱신했습니다.

## 무엇이 바뀌었나

1. 21~45라운드 75개 편성, 적군 417명에게 역할을 배정했습니다. 각 편성에 지휘관·엄호 장수·공격 장수·지원 장수·변수 장수를 지정하고 총 10종의 전장 전술 유형을 결합했습니다. 일부 편성은 4~5명만 등장해 역할이 생략될 수 있습니다.
2. 병력 역할을 이름의 해시값으로 무작위 배정하던 v15 구조를 대체했습니다. 이번 버전에서는 해당 전장과 함께 싸우는 동료를 보고 기술·약점이 정해집니다. 11~20R도 두 장수 연계 중심으로 보강했고, 1~10R은 원래 기본 전투를 크게 바꾸지 않았습니다.
3. 새 전장 기술이 **실제 전투 데이터**에 작동합니다. 전열 호위가 후열 피해를 10~18% 감소시키고, 전열 호위 사망 시 방어 효과 해제 및 후열 취약 상태가 발생합니다. 특정 호위는 누적 4회 피격 시 제한된 반격을 합니다. 보급 담당자는 7초 주기로 체력을 소모하며 아군을 회복합니다. 41~45R 등에서는 후방의 변수가 사망할 때 생존 적의 다음 기술 준비가 일회성으로 앞당겨질 수 있습니다.
4. 황개·주유·방통 화공 연계(30R 위 플레이), 마초·한수(35R), 장료(35R), 마속·왕평(42R), 학소(43R), 제갈량·사마의(45R) 등의 기존 개별 역사 모티브를 보존하고 전투 단위 연계에 편입했습니다.
5. 전투 전 화면에서 전술·6인 역할·약점·공략법을 펼쳐 볼 수 있습니다. 전투 중 연계 발동·사망에 따른 전술 붕괴·보급·반격·단절을 로그에 보여 줍니다. 전술 로그는 모바일에서도 줄바꿈하여 표시합니다. 패배 시 재도전 힌트를 덧붙입니다.
6. v15의 적 공용 스킬 0~2개 무작위 획득/시전과 재도전 시 보유 스킬 복원을 유지했습니다.

## 역사와 창작 구분

- 황개와 주유의 적벽 화공은 정사 모티브. 방통의 연환계 개입과 고육계의 상세 연출은 연의적 각색입니다.
- 장료의 합비 기습과 학소의 진창 수비, 마속의 가정 패전·왕평의 간언은 사료가 남은 사건입니다.
- 45R의 ‘합비신성 위명제 친정군’ 같은 게임 편성은 실제 역사 기록이 아니라 창작 시나리오입니다.
- 체력 퍼센트, 준비 시간, 연계·회복·반격 확률은 역사적 사실이 아닌 게임 규칙입니다.

참고 자료: 나무위키 `황개`, `적벽대전/진행`, `장료`, `왕평`, `학소`, `오장원 전투`, 그리고 삼국지연의 관련 항목. 전체 장수 113개의 개별 사료 해석을 검증 완료한 것은 아닙니다. 현재는 20개 핵심 장수 배치의 v15 역사 모티브를 유지하고, 전투별 75개 조합의 역할 전술을 새로 구현한 버전입니다.

## 검증 결과와 한계

- 외부 JS 7개 파일 및 `index.html` 내부 JavaScript의 구문 검사
- Chromium 실행 환경에 HTML을 주입해 21~45R 국가별 75개 편성·총 417명·45R 등급(SSS×2, SS×2, S×2) 확인
- 417명 고유 기술 및 무작위 공용 기술 약 300회 통제된 실행에서 JavaScript 예외 0건
- 1~20R 20개 라운드의 적군 생성과 신규 전술 연결 확인
- 황개-주유 화상 추가 피해, 정보 사망 전후 후열 피해 감소, 한수 사망 후 마초 강화, 마속 체력 소모, 학소 보호막, 제갈량/사마의 시간별 쿨타임 변화 단위 검사 정상
- ZIP 구성 및 JavaScript 구문, PWA 필수 스크립트 캐시 등록 확인

주의: 위 Chromium 검사는 전체 정규 게임 화면을 처음부터 마지막까지 플레이한 것이 아니라, 코드를 브라우저에 주입해 각 전투 함수를 통제된 조건에서 실행한 결과입니다. 전체 45라운드 연속 완주, SS급 4~5명 아군 조합별 승률, iPhone Safari/실제 GitHub Pages PWA, 기존 저장 파일의 실사용 환경 전체는 아직 미검증입니다. 113종 역사 모티브·42개 전장별 원본 v14 코드를 완전히 복원했다는 의미도 아닙니다.
