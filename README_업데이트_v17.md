# 삼국지 백팩 배틀즈 — v17 (2026-11-19)

v16 전술 개편을 그대로 유지하면서 사용자가 요청한 초기 금화·장수 크기·지도·의원 규칙을 보완한 업데이트입니다.

## 적용 방법

1. 기존 GitHub Pages 게임 폴더와 저장 데이터를 먼저 백업하세요. 게임 시작 화면의 **저장 백업** 기능을 활용할 수 있습니다.
2. ZIP의 `index.html` 및 모든 `.js` 파일을 기존 GitHub 저장소의 같은 위치에 덮어쓰세요. **index.html 하나만 교체하면 안 됩니다.**
3. 기존 `enemy_rounds_01_20.json`, `faces/` 이미지, `icons/`, `manifest.webmanifest`, `MAIN.png`, `MAP_BG.png`, `FIGHT.png` 등 게임 리소스는 그대로 남겨두세요. 이 ZIP에는 포함되지 않습니다.
4. GitHub Pages 배포 완료 후 iPhone Safari에서 **온라인 상태로** 게임을 열어 최신 파일을 받아 주세요. PWA 홈 화면 앱을 사용한다면 완전히 종료한 다음 다시 실행하세요. 서비스워커 캐시 이름은 `tk-battle-v17-rewards-clinics-map`으로 변경했습니다.

## 게임 규칙 변경

- **1~10R** 전투 후 3지선다 '금화발견': **1~3금화**. **11R 이후:** 기존 **2~4금화**.
- **1~10R** `?` 사건에서 얻는 금화: 사건별 **2~3금화**로 제한(최대 3). **11R 이후:** 기존 사건별 3~5금화. 황건 잔당·군량고·성문 사건에 적용.
- 각 라운드의 **기본 승리 보상, 적 처치 보상, 상점 가격은 변경하지 않음**. 따라서 10R 이전에 S 장수를 획득하는 것이 원천적으로 불가능해진 것은 아닙니다.
- **미축:** 참여 시 승리 보너스 **+2금화** (기존 v16에도 이미 +2로 설정되어 있었으며 유지 확인).
- **장수 크기:** 신규 장수/구버전 저장된 1×3 또는 회전 3×1 장수를 2×2로 통일. 기존 저장 배치는 2×2로 들어갈 수 있으면 유지하고 공간 부족 시 보관함, 꽉 찼다면 대기 명단으로 옮김. **긴배낭 1×3 확장 아이템은 대상에서 제외**.
- **의원:** 지도에서 2개 의원이 같은 연결 경로에 연속 등장하지 않도록 생성 및 구 지도 갱신. 지도 한 장에 보물 노드는 **1~2개**. 구 저장 지도는 아직 방문하지 않은 노드를 새 규칙으로 변경하되 이미 방문한 노드는 유지.
- **지도 의원 치료:** 살아 있는 배낭/보관함 장수 각각 **최대 HP의 20%** 회복, 최대 HP 초과 불가, 사망 장수는 부활하지 않음. `?`의 '떠돌이 화타' 성공 처방도 20%로 통일함. **다른 사건의 특별한 전체 회복 효과는 유지**.
- 골드 보상은 **수정 후 획득분**부터 적용되며 기존 세이브에 쌓인 금화는 회수하지 않음. 기존 세이브 보상 선택이 저장된 경우 보상을 받은 전투 라운드를 기록하여 구간 구분.

## 유지한 항목

v16의 1~45R 적군 편성, 역사 기반 기술·전술 연계, 등급, 공용 스킬, 난이도, 플레이어 장수 기술·능력치는 수정하지 않았습니다.

## 검증 (통제된 Chromium 실험)

- 최신 인라인 게임 스크립트 초기 실행 시 JavaScript 예외 0건
- 1~10R 보너스 금화 1/2/3, 11R 이후 2/3/4 추첨 확인
- 5종 사건 금화 보상 초반/후반 경계값 검사 완료
- 무작위 지도 **1,000개**: 지도당 보물 1~2개 **1,000/1,000**, 연결된 의원→의원 **0건**
- 구버전 지도 재배치(방문 완료 노드 보존) 및 신규 분포 버전 전환 확인
- 구버전 1×3 미축·유비 장수 **2×2 복구**, 1×3 가방 크기 유지 확인
- 저장 불러오기에서 구 장수의 HP·현재 라운드·지도 분포 및 보상 라운드 보존 확인
- 의원 회복: 최대 HP 150 중 현재 HP 20인 장수가 **HP 50**으로 회복, HP 0인 장수는 HP 0 유지
- 전투 후 보상 선택 실행에서 초반 1금화 지급 및 중복 수령 방지 확인

이 테스트는 전체 45R 연속 플레이나 iPhone 실제 기기·PWA 설치 상태에서의 테스트를 뜻하지 않습니다. 특히 초반 S급 획득 속도는 실제 여러 회차 플레이로 추가 밸런스 검증이 필요합니다.
