삼국지 백팩 배틀즈 — 전투 라운드 필수 진행 / 기존 정예전투 제거판

기준: 이전 「캐시·적군편성 오류수정 PWA」 전체 ZIP.

[라운드 규칙]
- 1~20라운드: 각 라운드에 지정된 적군과 반드시 전투. 5·10·15·20라운드의 기존 강한 지정 편성 유지.
- 21~40라운드: 20개 필수 전투. 41~45라운드: 5개 필수 전투(45라운드 최종 보스 유지).
- 의원/보물/사건은 같은 라운드에 놓이는 선택형 옆길. 방문 후 그 라운드 전투에 진입할 수 있음.
- 지원 장소 및 사건 방문·해결, 보물 획득은 라운드 번호를 증가시키지 않음.
- 사건에서 매복 전투가 발생해도 보너스 전투로 취급해 라운드 번호를 소모하지 않음.
- 라운드 번호는 지정된 필수 전투에서 승리했을 때만 1회 증가.
- 이전 무작위 정예 노드, 정예 추가 적군, 정예 전용 +20금화 삭제.

[이전 저장 파일]
- 기존 저장키와 장수/배낭/보물/금화 데이터 유지.
- 기존 맵이 새로운 규칙이 아니면 맵만 재구성.
- 연속으로 실제 승리한 전투 단계까지만 인정하고, 이벤트로 건너뛴 최초 라운드부터 전투를 다시 진행함.
- 이전 맵에서 방문한 선택형 장소는 재보상되지 않도록 완료 처리.
- 오래된 맵에서 순서가 뒤섞였다면 이미 방문한 일부 라운드를 재전투하게 될 수 있음.
- 새 맵 생성 후에는 필수 전투를 건너뛸 수 없음.

[유지 사항]
- 기존 105명 아군 초상화, 적군 전용 69장 얼굴 이미지, 전투 엔진/적군 특성·기술·이스터에그.
- 의원 기능, 보물 획득, 사건 15종, 병영, 9×9 배낭, 진형 효과.
- PWA 온라인 네트워크 우선, 오프라인 캐시 사용.

[검증]
- JavaScript 문법 검사 완료.
- 필수 전투 20/20/5, 1~20 순서, 의원·보물 라운드 미소모, 정예 삭제,
  이전 저장 데이터 마이그레이션, 최종 보스 유지 항목에 대해 Node VM 단위 검사 통과.
- 실제 iPhone Safari에서의 전체 플레이 검증은 아직 완료되지 않음.
