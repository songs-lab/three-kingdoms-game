# 삼국지 백팩 배틀즈 v18

기반: v17 전체 코드. v16 적군 기술·전술 엔진과 편성 유지.

- 새 출정 시작 금화 6 (이어하기 기존 금화 유지)
- 1~5R 기본 승리 1금화, 6~10R 2금화. 적 처치 보상 별도 유지. 11R 이후 기본 보상 유지.
- 1~10R 전투 후 3지선다 금화 1~2, ? 사건 금화 1~2. 11R 이후 기존 보상 유지.

- 떠돌이 화타 성공 시 생존 장수 체력 100% 회복. 실패 시 기존 체력 -10. 비용 5금화 및 성공 확률 50% 유지. 지도 의원 회복 20% 유지.
- 병영 선택 장수 완전 회복 가격 5금화.
- 적군의 기술과 전술 스크립트는 변경하지 않음. 검증 보고서는 별도 파일 참고.
